# Seguridad pre-alfa
LaNonApp v0.8 no es software clínico, de emergencia ni de pagos. No introducir datos reales de salud, finanzas ni identidad: localStorage y SQLite no están cifrados. Las llaves técnicas no acreditan representación legal. Eventos y recibos locales no son notificaciones enviadas ni acciones clínicas verificadas.

La investigación exige cifrado local, recuperación de claves, acceso autorizado, revocación comprobable, E2EE para sincronización, defensa ante inyección de contenido y pruebas independientes antes de operar sobre personas.
